# Attendance Planner

Attendance Planner is a student productivity web application designed to help students monitor and manage their class attendance. The application allows users to calculate their current attendance percentage, determine the number of consecutive classes required to reach a target attendance, and estimate how many classes can be safely missed while remaining above the desired threshold.

The application also includes a student profile system with local storage support, attendance status indicators, and a responsive user interface suitable for both desktop and mobile devices.

## Features

- Student profile management
- Current attendance percentage calculation
- Consecutive classes needed to reach a target attendance
- Safe absence allowance calculation
- Attendance status indicators
- Input validation and error handling
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Development

The initial codebase was generated with the assistance of Cursor AI as part of an AI-assisted development workflow.

Further customizations were implemented manually, including user interface refinements, logo integration, feature additions, improvements to attendance calculation logic, and testing of application functionality.
